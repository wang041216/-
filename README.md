# 协和 · 院区漫游

北京协和医院院区的静态互动导览原型，使用 HTML、CSS 和原生 JavaScript 编写，无需构建步骤。

## 本地预览

在浏览器中打开 `index.html`。

## 图片与参考资料

页面使用根目录及 `老楼/`、`老楼/协和人物/` 中的图片资源。已提供的建筑照片和历史图已用于老楼故事与院区沿革展示；图片原始来源、摄影信息或公开展示授权未随文件提供的，均在“资料与图片来源”页面标注为待核。

老楼 A–P 编号及历史用途按李美慧《北京协和医院各历史阶段建筑设计研究》[D]（北京建筑大学，2020，DOI: 10.26943/d.cnki.gbjzc.2020.000117）整理。该对应关系属于历史资料参照，不代表建筑现状或现场导航；相关书目、网页和实际使用图片清单见网站的“资料与图片来源”页面及 `sources.js`。公开部署前请逐项确认图片版权与传播许可。
