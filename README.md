# 协和 · 院区漫游

北京协和医院院区的静态互动导览原型，使用 HTML、CSS 和原生 JavaScript 编写，无需构建步骤。

## 本地预览

在浏览器中打开 `index.html`。

## 图片与参考资料

页面使用根目录及 `老楼/`、`老楼/协和人物/` 中的图片资源。已提供的建筑照片和历史图已用于老楼故事与院区沿革展示；图片原始来源、摄影信息或公开展示授权未随文件提供的，均在“资料与图片来源”页面标注为待核。

老楼 A–P 编号及历史用途按李美慧《北京协和医院各历史阶段建筑设计研究》[D]（北京建筑大学，2020，DOI: 10.26943/d.cnki.gbjzc.2020.000117）整理。地图首页保持单屏浏览，点击 A–P 点位或楼名跳转至含对应图片、建筑资料及参考来源的故事页；协和医学堂早期校舍见 `early-buildings.html`，院区时间线、A–P 楼宇功能及现代门诊楼发展见 `building-history.html`。J 楼是老院区历史门诊楼，与 1975 年奠基、1978 年开诊的后期门诊楼分开介绍。新增历史内容依据用户提供的《建筑.docx》整理；原文未提供来源或统计口径不一致的内容会标注待核，不替代院方现状信息。相关书目、网页和实际使用图片清单见网站的“资料与图片来源”页面及 `sources.js`。公开部署前请逐项确认图片版权与传播许可。
