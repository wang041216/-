# 协和 · 院区漫游

北京协和医院院区的静态互动导览原型，使用 HTML、CSS 和原生 JavaScript 编写，无需构建步骤。

## 本地预览

在浏览器中打开 `index.html`。

## 图片资源说明

本次 GitHub 上传仅包含网站代码，不包含地图、人物照片或其他图片文件。部分图片的公开传播授权尚未确认，因此暂不加入仓库。

页面完整呈现依赖根目录及 `老楼/`、`老楼/协和人物/` 中的图片资源。授权确认后，需将相应图片补入这些目录；图片清单与来源状态见网站的“资料与图片来源”页面及 `sources.js`。补齐获准发布的图片后，再启用 GitHub Pages 才能完整展示地图与人物配图。
